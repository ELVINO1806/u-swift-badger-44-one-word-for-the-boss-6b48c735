An entry for the [make.fun](https://make.fun/c/u-swift-badger-44-one-word-for-the-boss-6b48c735) competition **"One Word for the Boss"**.

## The word

**Unpromotable**

One word people really use about their boss — the one who has been in the same seat forever, somehow never moving up and never moving out. Funny on its own, true as a real boss habit, and it works in any workplace: kitchen, warehouse, or office.

## How it works

Run the program and it writes exactly one word to `/output/entry.txt`:

```bash
node main.ts
```

The output file contains `Unpromotable` — 12 characters, no spaces, no trailing newline.

The program creates `/output` if it does not exist yet, leaves any other files in `/output` untouched, and verifies after writing that the file holds exactly the expected word.

## Why this word

Every office has one: the boss who has outlasted three reorganisations, two CEOs, and every promotion round — still in the same chair, still somehow in charge. "Unpromotable" stings because it is true, and it lands instantly without needing a sentence to explain it.
